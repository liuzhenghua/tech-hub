正则语法速查

JavaScript 正则表达式 · 输入时不含外层 /，标志在工具栏选择。

字符与位置

语法 含义 示例
. 任意字符，默认不含换行 a.b 匹配 a-b
\d / \D 数字 0–9 / 非数字 \d+ 匹配 2024
\w / \W 英文字母、数字、下划线 / 其余字符 \w+ 匹配 user_1，不含中文
\s / \S 空白（含换行、Tab）/ 非空白 \s+ 匹配连续空白
[abc] / [^abc] 字符集合 / 排除集合 [a-z] 匹配小写英文字母
^ / $ 输入开头 / 结尾；m 模式下也匹配行边界 ^\d+ 匹配开头的数字
\b / \B 单词边界 / 非单词边界，以 \w 类字符为基础 \bcat\b 不匹配 scatter
\n / \r / \t 换行 / 回车 / 制表符 \r?\n 匹配常见换行
\.、\\ 转义元字符，匹配字面量点号、反斜杠 \. 匹配 .
\p{L} Unicode 字母，需启用 u \p{L}+ 可匹配中文、英文等字母文字

数量与贪婪模式

语法 含义 示例
* / + / ? 0 次及以上 / 1 次及以上 / 0 或 1 次 colou?r 匹配 color、colour
{n} / {n,} / {n,m} 恰好 n 次 / 至少 n 次 / n 到 m 次 \d{2,4} 匹配 2–4 位数字
*? / +? / ?? / {n,m}? 懒惰量词：尽量少匹配；默认量词尽量多匹配 <.*?> 在 <a><b> 中先匹配 <a>

分组与断言

语法 含义 示例
a|b 匹配任一分支 cat|dog
(...) 捕获组，按左括号顺序编号 (\d{4})-(\d{2})
(?:...) 非捕获分组 (?:ab)+
(?<name>...) 命名捕获组 (?<year>\d{4})
\1、\k<name> 反向引用已捕获的内容 (\w+)\s+\1 匹配重复单词
(?=...) / (?!...) 正向 / 负向先行断言，不消耗字符 \d+(?=元) 只匹配“元”前的数字
(?<=...) / (?<!...) 正向 / 负向后行断言，不消耗字符 (?<=￥)\d+ 只匹配“￥”后的数字

标志

标志 作用 注意
g 全局匹配 查找全部匹配，未启用时通常只返回第一个
i 忽略大小写 abc 可匹配 ABC
m 多行模式 改变 ^、$ 的行为，不让点号跨行
s 点号匹配换行 . 也可跨行匹配
u Unicode 模式 按 Unicode 码点处理，支持 \p{…}
y 粘连匹配 必须在当前位置匹配，失败时不会跳到后面搜索

本工具输入的是正则本身：匹配数字写 \d+，无需像 JavaScript 字符串字面量那样写成 "\\d+"。零宽匹配不消耗字符；位置按 UTF-16 计数，与 Unicode 码点数量可能不同。

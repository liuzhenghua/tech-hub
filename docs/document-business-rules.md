# 文档库业务规则

本文是文档列表、检索和导出共用的业务约定。修改这些功能时，先确认本约定；具体实现位于 `src/documents/`。

## 页面与路由

正文支持 `$…$` 行内公式和独立一行或多行的 `$$…$$` 公式块，使用 KaTeX 渲染；代码块、行内代码和转义的美元符号不解析为公式。错误或不支持的公式保留可读的源码提示，不阻断正文。HTML 导出将公式保存为静态 MathML，使用现代浏览器离线阅读，无需外部字体或脚本；PDF 打印保留当前公式渲染效果。

应用使用单一 HTML 入口和 Hash 路由，适配 GitHub Pages 静态部署：`#/tools` 显示工具目录，`#/docs` 显示文档库，文档详情使用 `#/docs?path=仓库相对路径&section=标题锚点`。不兼容旧的 `#tools`、`#docs` 路由。

顶部菜单和页面外壳共用；工具、文档各自封装成按需加载的页面组件。首屏只挂载 URL 对应的组件，不先展示工具后切换文档。路由切换销毁原页面的监听、定时器和未完成操作；文档会话由应用持有，切换菜单不清除已解锁的当前会话。锁定仍清除凭证和文档缓存。

顶部左侧显示当前页面标题：文档页为「私有文档库」，工具目录为「常用工具」；内容区域不再重复显示页面标题，列表数量保留在筛选栏上方。

仓库图片使用会话内存缓存，按仓库连接、提交版本与文件路径隔离，同一图片的并发读取合并为一次请求。缓存最多占用 32 MiB（按 Base64 字符串每字符 2 字节估算），超限淘汰最久未使用项，单张超限仍可加载但不缓存。切换文档或菜单可复用缓存；刷新页面、锁定、更换仓库连接或销毁会话后清空内存缓存，不另建持久化图片数据库。图片 HTTP 请求使用浏览器默认缓存策略，按 GitHub 响应头决定复用、条件验证或重新下载；请求 URL 带提交版本，版本变化后使用新 URL。浏览器 HTTP 缓存可能跨刷新保留，由浏览器管理，应用锁定不会清除它；固定提交版本的文件树、单文件提交时间和 Markdown 同样使用默认 HTTP 缓存；最新提交检查使用 `no-cache`，允许条件验证并始终检查更新。初始化通过默认分支最新提交列表直接取得 SHA，再读取该版本文件树，不再先查询仓库信息和分支引用。失败请求不缓存；连接关闭后旧异步结果不得回填缓存。图片显示使用的临时 Blob URL 仍在离开文档时释放。

## 主文档与子文档

**`standalone` 是可选字段，只有 YAML 布尔值 `false` 表示子文档。未声明或设置为 `true` 的文档都是主文档。** 字符串 `"false"`、`null` 等其他值沿用主文档默认行为。主文档名称没有约定，不根据 `README.md`、`index.md`、正文标题或引用关系改变文档身份。

存在子文档的文件夹应只有一个主文档，子文档均归属于它。子目录中的子文档从所在目录向上寻找最近的唯一主文档；遇到有主文档的目录即停止，因此嵌套目录可以有自己的主文档。归属不跨文档库边界；同一子文档只属于一个主文档。

```text
docs/主题/
├── 任意名称.md          # 未声明 standalone：主文档
├── 操作细节.md          # standalone: false：归属任意名称.md
└── 示例/
    └── 说明.md          # standalone: false：向上归属任意名称.md
```

同目录包含多个主文档时，它们保持独立；若该目录还有子文档，则数据违反“唯一主文档”的约束，系统不按文件名、列表顺序或链接猜测归属。没有主文档的孤立子文档同样不自动改成主文档，仍可通过直接链接访问。

## 索引与检索

主文档卡片按该文件在当前仓库快照中的最后提交时间（committer date）倒序排列，分类和检索结果沿用此顺序；时间相同时按仓库路径升序，缺失时间的排在末尾并提示。子文档修改不改变主文档的排序时间，子文档列表和 ZIP 顺序仍遵循仓库索引顺序。修改时间在解锁后与正文索引并行补全，不阻塞打开文档和图片，通过带认证的提交查询获取，并发上限为 3；同一仓库快照中已获取的时间可复用缓存，仓库快照变化后重新查询。时间查询失败不阻止浏览，后续连接时重试。

同一会话中同一路径的并发正文读取合并，失败后可重试，更换连接时清理。构建文档库时读取全部文档的元数据和正文索引，再生成主子关系，不依赖卡片是否进入视口。刷新时先展示已有缓存，联网后在后台补全索引，不清空文档卡片；尚未连接仓库不视为索引失败。索引并发上限为 3；真实失败只显示简短提示和重试按钮，完整路径清单默认折叠，展开后限制高度。文件 SHA 变化时使对应缓存失效，重新索引；切换仓库、锁定或销毁会话后，旧异步结果不得写回。

列表、分类和数量只统计主文档。卡片底部的子文档数量在悬浮或键盘聚焦卡片时展示已归属子文档列表，按仓库索引顺序显示标题（缺失时使用文件名）；点击列表项打开对应子文档，点击卡片主体仍打开主文档。检索匹配主文档及其子文档的路径、标题、摘要和完整正文，忽略大小写。**子文档命中后只展示所属主文档，底部标注“命中 X 篇子文档”，悬浮列表只展示命中的子文档；不在卡片正文逐项罗列。仅主文档命中时不显示子文档数量；多个子文档命中不重复展示主文档。** 分类按主文档路径计算，点击结果打开主文档。索引失败时提示搜索和归属可能不完整。

索引正文在当前会话中保留；启用“记住口令”后随摘要以明文尝试保存到浏览器 localStorage。存储不可用或额度不足不阻止当前会话检索，重新打开页面时可能需要联网重建。

## 复制与导出

| 操作              | 范围                                                       | 结果                                                                                  |
| ----------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 复制 Markdown     | 当前打开的文档                                             | 原始 Markdown 全文，包含文件头                                                        |
| 当前文档 Markdown | 当前打开的文档                                             | 原始 `.md` 文件                                                                       |
| 当前文档 HTML     | 当前打开的文档                                             | 单个离线 `.html`，内嵌样式、已加载的本地图片和已渲染的 Mermaid 图表，无需口令即可阅读 |
| 包含子文档        | 当前文档所属主文档及全部已归属子文档、各文档引用的本地图片 | `.zip`，保留仓库相对目录、原始 Markdown 和本地图片字节                                |
| 当前文档 PDF      | 当前打开的文档                                             | 打印当前渲染正文；暂不合并子文档                                                      |

ZIP 与列表、检索使用同一套主子关系，不另行通过正文链接扩大范围，也不打包同目录中其他独立主文档。从子文档执行打包时，同样导出其所属主文档组。没有子文档的主文档仍可打包自身和本地图片。

HTML 是导出时当前文档的静态快照，不附带子文档、仓库访问凭证或页面操作控件。文内标题锚点和 HTTP/HTTPS 链接保留；关联仓库文档不随文件收录，其导航链接禁用。外部图片不自动下载，保留未收录说明；本地图片加载失败或 Mermaid 渲染失败时阻止导出并提示重试，不静默生成缺图文件。HTML 无需脚本或联网资源即可阅读，接收者可继续转发文件，导出后无法撤销。切换文档或销毁页面后，旧导出结果不得触发下载。

ZIP 首先收录主文档，再按仓库索引顺序收录子文档；同一路径只收录一次。本地图片包括 Markdown 图片、引用式图片和 HTML `img src`，支持 PNG、JPEG、GIF、WebP、SVG、AVIF、BMP、ICO、APNG。外部 URL、data URL 和代码示例中的图片不自动下载；不处理 HTML `srcset`、CSS 引用的资源或 SVG 内部的外链。指向组外文档的相对链接保留原文，目标文档不随包附带。

索引未完成或存在失败项时，不猜测导出范围，提示重试。已确定范围内的文档、图片读取失败或图片路径非法时，列出缺失项，允许重试、取消或明确选择导出已有内容；不完整的 ZIP 附带 `EXPORT-MISSING.txt`。文档范围限制在配置的文档目录，本地图片路径可以指向仓库其他目录，但不得超出仓库。单包最多 500 个文件、原始内容合计最多 50 MB，超过后停止并提示拆分。

切换文档、返回列表、锁定或销毁页面时，未完成的打包操作失效，关闭缺失清单；旧结果不得触发下载或覆盖新页面提示。
